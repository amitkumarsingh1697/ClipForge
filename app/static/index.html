▶YouTube Shorts

  1. Open Google Cloud Console and create a project (free).
  2. Enable YouTube Data API v3.
  3. In Google Auth Platform: External, add yourself as a test user, then Publish app so sign-in doesn't expire after 7 days.
  4. Create an OAuth client of type Desktop app, download its JSON and upload it here.
  5. Press Connect YouTube and allow access (if Google says "unverified": Advanced → continue).
Connect YouTube

Uploads are public (YOUTUBE_PRIVACY in .env). After every upload ClipForge asks YouTube who can actually see the video. If Google locked it to private because your Cloud project hasn't been audited, the publish steps say so: fill in the free YouTube API audit form, and meanwhile upload those clips from the YouTube app.

◎Instagram Reels

  1. Switch Instagram to a Professional (Business or Creator) account linked to a Facebook Page.
  2. Create an app at Meta for Developers and add the Instagram product.
  3. Generate a long-lived token with instagram_content_publish, and copy your Instagram account ID.

fFacebook Reels

  1. You need a Facebook Page (not a personal profile). Facebook pays Pages for Reels views through its content monetization programme.
  2. In the same Meta app as Instagram, open Graph API Explorer and get a User token with pages_show_list, pages_read_engagement, pages_manage_posts.
  3. Exchange it for a long-lived token, then call me/accounts: copy your Page's id and access_token (that Page token doesn't expire).

Facebook Reels must be 90 s or shorter; longer clips skip Facebook. Meta allows 30 API reels per Page a day.

♪TikTok

  1. Create an app at TikTok for Developers and add Content Posting API (Direct Post) and Login Kit.
  2. Sign in with your TikTok account through the app to get an access token and refresh token (scope video.publish).
  3. Paste them here. Until TikTok audits your app, posts are private (only you can see them).

AI model

Optional. An LLM writes the hook, titles (with A/B alternatives), caption and hashtags from what is said, and can help pick the best moments. Local models keep everything on this computer. Cloud models need an API key from their developer console: the ChatGPT, Claude or Gemini apps themselves can't be connected.
